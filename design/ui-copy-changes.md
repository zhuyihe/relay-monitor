# 界面用语改动记录

这份记录按页面列出，界面上的话照 `design/ui-copy-spec.md`（下称「规范」）改了哪些，给财务、运营和开发对照用。改动分三批：A1、A2、A3。这里先记 A1，A2 和 A3 在各自的 PR 里接着往下写。「原来」「现在」两列都照代码原样抄；`X`、`N` 表示会填进名称、时间或数字的地方。

## A1 · 共用的文案来源

同一句话只在一处定义，页面都从这里取（规范 §12）。

| 模块 | 管哪些话 | 哪些地方在用 |
|---|---|---|
| `lib/reconciliation-contract.js`（ISSUES，§5） | 每种问题的标题、说明、实时时的提示和按钮；渠道状态（§5.6）；「这把 Key 还给别处用吗？」和它的回答；「N 个渠道里 M 个已算进利润」 | 每日利润、渠道绑定、改绑定、上游账单；服务端的推送、每日利润和渠道绑定接口 |
| `lib/workflow-actions.js`（ACTIONS，§3.5） | 按钮名和完成提示；测试读取的结果句；「这条已经变了，刷新后再看。」；「以前的每日记录还在」 | 渠道绑定、改绑定、上游账单、上游资源页、每日利润、运营总览「需要处理」和侧栏计数 |
| `lib/error-copy.js`（§8.2） | 报错归成 13 类，每类一句话和一个下一步按钮；`failureText` / `failureSentence` 拼成「X：原因。」；`requiredText` 写漏填「请填 X」 | 渠道绑定、改绑定、上游账单、每日利润和计算明细；`lib/client.ts`；服务端每日利润 |
| `lib/format.js` | 「1 美元 = X 元」；「已删除的上游」；两句没设置汇率；「还没设置自营站点」；「没有需要处理的事。」；「计入固定成本」；「数据截至 14:30」；「刷新失败，数据截至 X。」；按哪个时区算一天；日期和日期范围 | 每日利润各块、上游账单、渠道绑定、改绑定、运营总览 |
| `lib/channel-onboarding.js`（BINDING_COPY） | 「预览」「请至少选一个渠道」「还在用这把 Key 但没绑定的渠道」「读不到自营站点的渠道」「暂停监控」「自营站点」；用途「看余额」「算利润」、两种用途各做什么的那句、「只用 Key 的上游要选「看余额」」 | 渠道绑定、改绑定、上游账单、每日利润 |
| `server/reconciliation-repository.js`（REPOSITORY_ERRORS） | 读写绑定时的 6 种报错，每种带一个码；MySQL 版和测试用的内存版抛同一个码、同一句话，界面按码归类 | 每日利润接口 |
| `app/components/error-detail.tsx` | 收起的「查看详细原因」：标题「发给技术同事看」、报错原文、「复制」 / 「已复制」 | 渠道绑定、改绑定、上游账单；每日利润的汇总、绑定列表、计算明细和以前的每日记录 |

每日利润页的按钮名（「刷新」「重新读取」「去设置」「以前的每日记录」）放在 `recon-format.ts` 的 RECON_BUTTONS，值都取自 `lib/workflow-actions.js`；「去设置」的地址也取自那里，和「需要处理」里的同一个。

页面名和标签页名在 `lib/brand.js`，有两处改动：
- 导航「账单核算」→「每日利润」，「监控估算」→「成本估算」。
- 新增标签页名表 STATION_TABS：「上游列表」「渠道绑定」「上游账单」。

- **整页读不到。**原来写「无法加载账单核算」或「无法读取核算数据」，带报错原文和「重新加载」「重新查询」。现在写「读不到每日利润：原因。」，原因按 §8.2 归类，加「刷新」，原文收进「查看详细原因」。有旧数据时写「刷新失败，数据截至 X。」，加「刷新」。
- **读不到自营站点的渠道。**原来直接把报错原文当标题。现在和渠道绑定里同一句「读不到自营站点的渠道：原因。」，原文收进「查看详细原因」。
- **首次加载。**原来写「正在读取账单核算」，现在是「汇总」和「绑定列表」两块骨架屏。
- **还没设置自营站点。**原来是「还不能开始核算」「前往上游资源」，或「本站管理员站点未配置」「前往配置」。现在统一成「还没设置自营站点」，后面跟「在上游资源里编辑你的 New API 站点，打开「这是我的自营站点」。」，按钮「去设置」。
- **没设置汇率。**原来是「金额按系统原值（美元）显示」「去设置汇率」，现在是「没设置汇率，按美元显示」「没设置汇率的：名称」「去设置」。
- **汇总下面删掉的：**
  - 「全量汇总读取失败 · 摘要仅供参考」和「重读全量汇总」；
  - 「仅已确认范围的金额，不代表全站完整利润。」；
  - 汇率、账号扣费时间和核算关联编号那一行。
- **汇总下面改写的：**
  - 币种说明改成「按各自设置的汇率换算成人民币（已固定的日子按固定时记下的汇率）。」；
  - 实时预设下加一句「今天的数字还会变，过了零点自动固定。」；
  - 有包月上游时写「包月上游的上游成本写「计入固定成本」；扣掉固定成本后的净利见自营业务。」
  - 「未计入成本的关联：rule-1、rule-2。」改成「上游成本没算进来的绑定：Key 名、Key 名。」，写 Key 名不写编号；原来只在分组小计里有，现在只有一份汇总时也写在汇总下面。
- **没算进利润的上游成本。**
  - 说明改成「上游扣费（和「自营业务」读的是同一个数）减去已算进利润的上游成本。」
  - 状态原来是「已取全」「估算」「部分」「读取中」「读取失败」。现在读全了不加标签，估算的数字前加「≈」，其余写「没读全」「读取中」「读不到」。
  - 已算进利润的多于扣费时，写「有的上游已算进利润的多于上游扣费，合计里按 0 算。」
  - 按钮「查看各上游账号」改成「查看各上游」。
- **渠道。**原来写「已知渠道覆盖：已核算 x/y」，现在写「N 个渠道里 M 个已算进利润」，按钮「查看没算进来的」。每个渠道显示状态标签、原因和按钮，不再列核算关联编号。
- **列表按钮和筛选。**
  - 行内「重试」改成「重新读取」。
  - 行内的「重新读取」和需处理按钮，读屏时都带上 Key 名，例如「更新登录信息 Key A」，手机版也一样。
  - 「去上游账单处理」删掉，页头说明改成「每天的收入、上游成本和毛利。去绑定、改绑定、解除绑定请到上游账单。」
  - 筛选只剩「全部」「需处理」「亏损」，「切换待确认 N」删掉。
- **计算明细。**
  - 只留这些行：时间、上游、Key、分组 / 倍率、收入、上游成本、毛利、毛利率、汇率、固定于、开始统计、改过。
  - 删掉的行：请求窗口、返回账单实际窗口、当前核算范围版本、首次结账、账单时区能力、风险差额等。
  - 汇率写「1 美元 = X 元，X 固定时记下」。收入和上游成本的汇率不同时，写「收入按 A，上游成本按 B」。
  - 单条重新读取没成时写「重新读取没完成，请稍后再试」。
  - 倍率时段旁的说明：「切换时间待确认」改成「倍率变化的时间是系统估的」，「已人工确认」改成「倍率变化的时间是手动改的」，「初始分段」不再写。
- **以前的每日记录。**
  - 删掉「第 N 版」「迁移的旧账」「原账单窗口」「原本站来源」「成本计法」「结账版本」等。
  - 改过的写「改过 N 次」。
  - 区块下写「每天固定后不会再变，也不算进上面的汇总。默认看最近 31 天，一次最多查 31 天。」
  - 读不到时，「历史读取失败，请重试」改成「读不到以前的每日记录：原因。」；「历史关联目录读取失败」改成「读不到绑定列表：原因。」；「重试」改成「刷新」。
- **从「需要处理」点进来的那一条。**
  - 标题写「Key 名 · 日期」。
  - 按钮「重查该窗口账单」改成「重新读取」，「原确认历史」改成「以前的每日记录」，「刷新处理目标」「返回当前账单」改成「刷新」。
  - 「去上游账单处理」和「涉及关联：…历史账单保留。」删掉。
  - 绑定已经没了时，写「这条绑定已解除」。

## A1 · 状态和问题

- **每天只剩三种状态（§4）。**
  - 原来列表状态有「正常」「待确认」「数据过期」「负毛利」，问题标签有十几种，例如「数据正常」「分组或倍率已变化」「分段切换时间待确认」「Key 不可用或无权限」「渠道来源待核对」，颜色各异。
  - 现在只有「实时」「已固定」「需处理」三种。另有四个标签：「改过」「亏损」「≈」；渠道上还有「已停用」或「已删除」。
- **实时和已固定的写法。**实时旁边写「数据截至 14:30」，过去的日子再加「还在读取」；已固定悬停写「X 固定」。
- **需处理的写法。**只露出最要紧的一条和一个按钮，其余收起成「还有 N 个问题」，利润写「—」。
- **问题按 §5 分三类。**
  - 需处理：9 个码，共 7 句。
  - 读取类：7 个码，另加 4 个旧码。今天和过去 7 天里只当提示显示，过了 7 天还没读到才变成需处理。
  - 提示类：8 个码，不改状态。
- **旧码。**STALE、GROUP_OR_RATIO_CHANGED、BILLING_WINDOW_UNCONFIRMED、OWN_FLOW_INCOMPLETE 都写「这天的数据不完整」（§5.5）。
- **认不出的码。**写「这条暂时算不出利润」，加「刷新」；码只写进浏览器控制台（`[每日利润] 不认识的问题码：…`）。
- **渠道状态（§5.6）。**只用「已算进利润」「没绑定」「从 X 开始统计」「需处理」「还在读取」「只看余额」「读不到账单」。
- **原来的两句提示。**「关联生效前，不计金额」改成「从 X 开始统计」，「已按新配置重算」改成「改过」。
- **还没做。**§4 的多天合计写法这次没做，例如「7 天已固定」「其中 2 天需处理，没算进来」。

# 文档总目录

想知道一件事，就看右边写的那一份的那一节。目标是每个主题只有一份来源，别处说到它都只链接过来；还没做到、两处写得不一样的地方，列在[待改总表](./pending.md)第五、六节。

- 「现在」是页面上已经这样；「以后」是已经定了、还没做完的，做到哪见[待改总表](./pending.md)。
- PR 代号：C 是结账可靠性，K（K1a–K2d）是认 Key、渠道跟着 Key 走，D 改设置，E 需处理清单，F 多天拼装，G 金额币种（还有「等式只放两处」，这一件的页面设计 G 开工时出），第一次使用是「开始使用」清单和两个抽屉，后面的状态表里有各自的设计稿；合页是用量分析并进成本估算（[体检](./ui-audit.md) §8.4 第 4 件），版式见[逐页版式](./ux/page-layouts.md)第 6 节。K 设计稿是 10-24 的旧稿，留下的几样已经并进流程梳理稿，挪进了[历史文档](./history/README.md)。
- 开发的 K 方案、C 方案和审核的性能基线是工作文件，不在仓库里；里面定下的规矩已经写进这里的文档（性能门槛见 [CONTRIBUTING](../CONTRIBUTING.md) 第 4 节）。排期也不在仓库里。
